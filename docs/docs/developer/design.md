# Design

## Tools & Technologies

- **Penpot**: UI/UX design tool for creating visual mockups and prototypes
- **Flutter Widgets**: Implementation of designs using Flutter's widget framework

## Workflow

1. Design mockups and layouts in Penpot
2. Export design specifications
3. Implement designs using Flutter widgets
4. Iterate based on feedback
