# Roadmap

### Phase 1: MVP (Current)
- Auth/Registration via **Supabase**.
- Vehicle CRUD (Create, Read, Update, Delete).
- Basic maintenance algorithm (Mileage -> Alert).

### Phase 2: Monetization & Local-First
- Affiliate integration (Amazon, Autodoc).
- Community Workshop Manuals (PDF).
- **Local-first** cloud sync via personal Google Drive.

### Phase 3: Servers & API Ecosystem
- **Self-host** option for workshops.
- Advanced Cloud Sync & Multi-device sharing.
- Vehicle API integration for real-time mileage and diagnostics.
- External Alerts (Telegram, Email, Desktop) via Server Cronjobs.

### Phase 4: AI & Collective Intelligence
- **Cloud OCR:** Scan workshop invoices to auto-fill history.
- **Reliability Rankings:** Anonymous community data to predict common failures per model.
- **Price Monitoring:** Tracking oil/tire prices to alert users of discounts.
