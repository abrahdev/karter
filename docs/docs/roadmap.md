# Roadmap

### Phase 1: MVP ✅ (v2026.06.1-alpha)
- Vehicle CRUD with type selector (Combustion / Electric / Motorcycle).
- Composite identifier (Brand + Model + Year) with optional alias.
- Fuel log with price per unit and full tank indicator.
- Maintenance log with odometer at service, interval reset.
- Configurable maintenance intervals (km + time-based), per vehicle.
- Preset intervals per vehicle type with descriptions.
- Odometer quick-update dialog with increment buttons and validation.
- Maintenance alerts (km overdue + time overdue).
- Delete vehicle with cascade confirmation (red button in edit form).
- NavigationBar (Dashboard / Vehicles / Más).
- Editable interval descriptions.
- Linux desktop support.
- Local-first (SQLite via drift), no cloud dependency.

### Phase 2: Dashboard & Data (Current)
- Dashboard with charts and statistics.
- Export / import data (JSON / CSV).
- Search and filter logs by date, type, cost.

### Phase 3: Sync & Notifications
- Local-first cloud sync (Google Drive / Nextcloud).
- Push notifications for due services.
- Multi-vehicle sharing (read-only / write).

### Phase 4: Monetization & Community
- Affiliate integration (parts, tools) with 20% NGO donation.
- Community workshop manuals (PDF).
- Reliability rankings from anonymous community data.
- Price monitoring for oil, tires, filters.
