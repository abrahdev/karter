# Contributing
Thank you for your interest in contributing! Here's how you can help:

### Report issues
By far the easiest way to help make Karter better it to use it and report issues and bugs. Found a bug? Open an issue on GitHub.

### Translations
Support the project by localizing on Weblate. For more information, see the Translations section.

### Development
If you are a programmer or developer, take a look at Karter's technology stack and consider fixing bugs or building new features. The team and I are always looking for new contributors. For information about how to contribute as a developer, see the Developer section.
